# CLAUDE.md

Read and follow `AGENTS.md` before making changes in this repository. It is the
canonical, tool-neutral guidance for architecture, dependency boundaries,
required checks, documentation maintenance, and the Gather companion-game rule.

Claude-specific guidance belongs here only when it cannot reasonably apply to
other coding agents. There is currently no Claude-specific override.


For any change to `decay-lsp`, Decay editor integration, batch preflight,
structured Decay diagnostics, or agent-facing Decay tooling, also read and
follow `docs/decay-lsp-modernization.md`. Its checklist is the active source of
truth for the audited tooling gaps and must move with the implementation.
