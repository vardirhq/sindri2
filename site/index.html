  @export var speed: f32 = 6.0;

    let x = Input.axis(
      "ArrowLeft", "ArrowRight"
    );
    this.transform.position.x +=
      x * speed * dt;
  }

DECAY

A gameplay language that refuses to guess.

Host members are typed. Exported properties are inspectable without executing code. Misspell a component path and compilation fails at the source location instead of exploding three frames later.

Scripting guide →Language reference
player.decay
@export
var speed: f32 = 6.0;

fn update(dt: f32) {
  let movement = Input.axis(
    "A", "D"
  );

  this.transform.position.x +=
    movement * speed * dt;

  if Input.just_pressed("Space") {
    Audio.play("jump.ogg", 0.8);
  }
}
